# E-Commerce SQL Project

## Project Description
This project is about managing E-Commerce data using PostgreSQL. It stores customer, product, and order information and performs SQL analysis.

## Technologies Used
- PostgreSQL
- SQL
- pgAdmin 4

## Database Tables
1. Customers
2. Products
3. Orders

## SQL Queries
1. Display all orders with customer and product names.
2. Calculate total order amount for each customer.
3. Find the number of orders for each status.
4. Find the product with the highest total sales amount.
5. Find customers who have not placed any orders.

## Project Structure
```text
SQL_Queries/
├── sql/
│   ├── create_tables.sql
│   ├── insert_data.sql
│   └── analysis_queries.sql
└── README.md
```

## How to Run
1. Open PostgreSQL using pgAdmin 4.
2. Select the SQL_Queries database.
3. Execute create_tables.sql.
4. Execute insert_data.sql.
5. Execute analysis_queries.sql.
